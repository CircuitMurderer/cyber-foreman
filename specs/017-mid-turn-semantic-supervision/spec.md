# SPEC-017：运行中语义抽检与自动纠偏

- 状态：IMPLEMENTED
- 创建日期：2026-10-08
- 最后更新：2026-10-08

## 背景

结束后语义复核只能在 Agent 已经完成一轮工作后发现跑偏。对于修改错误模块、忽略关键约束等明确偏航，等到回合结束会浪费时间和模型额度。

## 目标

- 在 Agent turn 执行期间低频采样可见回复并进行保守语义判断。
- 对明确跑偏使用现有取消与同 session follow-up 机制及时纠偏。
- 复用确定性 Decision、Executor、去重和预算边界。
- 默认关闭，并允许内网部署按模型成本和速度显式配置。

## 非目标

- 不读取或推断模型隐藏思维。
- 不对每个流式 chunk 调用监督模型。
- 不允许运行中抽检直接执行 Shell、修改文件或请求人工升级。
- 不用语义判断替代回合结束后的 Git、测试和安全验证。

## 功能要求

- REQ-001：运行中抽检必须显式启用，默认关闭。
- REQ-002：每次抽检同时受时间间隔、最小可见输出长度和单 turn 最大次数约束。
- REQ-003：抽检异步执行，不阻塞 Agent 事件消费和确定性超时规则。
- REQ-004：只有明确 `redirect` 才能触发 `cancel_and_follow_up`。
- REQ-005：纠偏必须使用语义纠偏预算，并在当前 Agent session 追加指令。
- REQ-006：过期抽检结果、模型错误、非法输出和预算耗尽均 fail-open。
- REQ-007：运行中阶段不得向模型暴露 `request_operator_attention`。
- REQ-008：Agent turn 正常结束后仍执行确定性验证及结束后语义复核。

## 验收标准

- AC-001：测试证明运行中 redirect 会取消一次并在同 session 继续。
- AC-002：测试证明请求明确标记 `mid_turn`，且不暴露人工升级工具。
- AC-003：配置测试覆盖默认值、非法值和 tool-calling 前置条件。
- AC-004：事件流能区分运行中抽检和结束后复核。
- AC-005：全量测试、vet、race 和前端构建通过。
